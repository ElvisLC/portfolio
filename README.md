# Portfolio

Este repositorio contiene el código fuente del portafolio personal.

El proyecto está construido con un stack moderno enfocado en rendimiento, simplicidad y mantenibilidad.

---

## Stack tecnológico

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

---

## Requisitos

- Node.js (recomendado vía nvm)
- npm

---

## Instalación y ejecución en local

Clona el repositorio:

```bash
git clone <REPOSITORY_URL>
cd <PROJECT_NAME>
Instala las dependencias:

bash
Copiar código
npm install
Inicia el servidor de desarrollo:

bash
Copiar código
npm run dev
La aplicación estará disponible en el puerto configurado por Vite.
